     5→## Project Overview
     6→A dockyard ERP admin panel built with Next.js 16 + TypeScript + Tailwind CSS 4 + shadcn/ui + Prisma (SQLite).
     7→Single-page app with state-based module switching (only `/` route is allowed).
     8→
     9→## Tech & Conventions
    10→- Dark theme (bg `#0f1420`, card `#1a1f2e`, border `#2d3548`, primary `#3b82f6`)
    11→- shadcn/ui components in `src/components/ui/`
    12→- ERP common components in `src/components/erp/` (StatCard, badges, PageHeader, states)
    13→- Custom hook `useFetch` + `apiRequest` in `src/lib/use-fetch.ts`
    14→- Constants & helpers in `src/lib/constants.ts` (PRESENT_POSITIONS, FILE_CATEGORIES, formatCurrency, positionColor, etc.)
