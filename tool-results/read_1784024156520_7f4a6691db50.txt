     5→     5→## Project Overview
     6→     6→A dockyard ERP admin panel built with Next.js 16 + TypeScript + Tailwind CSS 4 + shadcn/ui + Prisma (SQLite).
     7→     7→Single-page app with state-based module switching (only `/` route is allowed).
